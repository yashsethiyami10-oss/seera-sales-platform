# MUV — Operational Dependency Audit

**Founder Execution Protocol — Stage: MUV Operational Dependency Audit™ v1.0.** Pure audit — no
code, no architecture, no implementation was performed to produce this document. Every claim below
was verified directly against this repository's actual files (`.env.example`,
`.env.production.example`, `package.json`, `prisma/schema.prisma`, `DEPLOYMENT_GUIDE.md`,
`DEPLOYMENT_READINESS.md`, `PRE_LAUNCH_CHECKLIST.md`, and the relevant `lib/*`/`app/*` source) —
not assumed. Where `PRE_LAUNCH_CHECKLIST.md` and the live codebase disagree (it says `/about`,
`/contact`, `/shipping`, `/returns`, `/faq` "currently 404" — they do not; all five pages exist and
were confirmed via direct file read), this audit trusts the live code, per CLAUDE.md's own rule
to verify against actual code rather than a possibly-stale status doc, and flags the doc as stale.

**Companion documents**: `SUBSCRIPTION_REQUIREMENTS.md` (cost roll-up), `LAUNCH_CHECKLIST.md`
(sequenced action list), `PRODUCTION_CONFIGURATION_GUIDE.md` (exact env vars/values),
`FOUNDER_OPERATIONAL_REVIEW.md` (executive summary). This document is the detailed reference the
other four are built from — read this one for "why," the others for "what to do."
