# Security Audit

Threats challenged include cross-portal access, cross-partner scope, forged retailer assignment, assisted impersonation, partner self-credit editing, grace/promise mutation, negative stock, direct balance overwrite, duplicate submissions, historical price mutation, booked-performance inflation, and joint-work double counting.

Controls are centralized permission checks, active party membership, effective-dated assignment, immutable snapshots, unique idempotency keys, movement replay, explicit financial acceptance, audit/status history, and separate portal registries. Critical bypasses found during audit were fixed before regression.
