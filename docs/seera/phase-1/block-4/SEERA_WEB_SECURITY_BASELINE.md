# Web Security Baseline

Global headers cover frame denial, MIME sniffing, strict-origin referrers, permissions policy, HSTS, hidden framework identity and a tested self-oriented CSP. Auth/foundation APIs and portals are no-store/private. Login errors avoid enumeration and expose loading/disabled/alert semantics. Rate limiting is process-local only: implemented and adapter-ready, but a distributed production store remains a deployment dependency before horizontal scaling.
