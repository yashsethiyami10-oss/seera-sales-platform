# Seera Phase 1 Seed Strategy

No seed ran in Block 2. Future foundation seeding will be idempotent and test-target guarded. It may create only canonical permissions, the 14 base roles, feature flags, app settings, and a secure Founder/Super Admin bootstrap mechanism. Role codes and permission namespaces are defined in `lib/foundation/rbac-catalog.ts`.

MUV seeds and business/sample records are prohibited. Retailers, distributors, super stockists, products, orders, finance, and sample commercial data remain out of scope.
