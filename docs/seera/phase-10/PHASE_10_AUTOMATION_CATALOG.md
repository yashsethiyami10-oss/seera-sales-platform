# Phase 10 Automation Catalog

Persistent rules carry a language-independent code, category/event, JSON condition, recipient scope, channels, bilingual template key, default language, enable switch, timing offset, priority, governed severity, cooldown and configuration. Executions have a unique rule/event/recipient key, retry state, source metrics and provider references.

Supported architecture covers order, payment, credit, stock, target, field, document, partner and TA events. In-app is canonical. Email and WhatsApp Business are provider-neutral; the WhatsApp adapter requires an approved template identifier and records provider state. Live credentials are deliberately not required for local freeze evidence.
