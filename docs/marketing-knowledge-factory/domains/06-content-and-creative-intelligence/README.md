## Critical cross-domain duplication risks — identified and resolved before authoring began

Given this domain's explicit "merged domain" framing and the scale of overlap found (Domains 1,
2, 4, and 5 all contain directly relevant content), the single greatest risk to this domain was
silently re-authoring content that already exists elsewhere under different section names. This
is resolved structurally: **Chapters 1–5 contain only content with no frozen-domain equivalent
(verified section-by-section during research); Chapter 6 contains zero new source
transcription, only verified citations; Chapter 7 contains zero source content at all, only
honest gap records.**
