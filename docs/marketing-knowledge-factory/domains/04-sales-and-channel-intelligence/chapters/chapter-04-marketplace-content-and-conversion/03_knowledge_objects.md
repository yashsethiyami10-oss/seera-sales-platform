- **Purpose:** Establish the seven-stage conversion path and the nine-element listing
  information architecture, with the content-cannot-compensate rule.
- **Scope:** Conversion Philosophy (Figure 4.1), Listing Information Architecture, complete.
- **Inputs:** MUV Knowledge Library, Part VIII, Ch.39 (Conversion Philosophy, Listing

- **Outputs:** Figure 4.1 seven-stage path; nine-element listing table.
- **Dependencies:** None (chapter-opening KO).
- **Relationships:** governs KO-SC-CH4-002 through 010.
- **Governance Rules:** *"Conversion should be the result of informed confidence, not missing

  stock, delivery, or reviews."*
- **Validation Rules:** Figure 4.1's seven stages preserved in exact order; all nine listing

- **Version:** 1.0
- **Status:** Founder Review Ready
- **Change History:** 2026-07-31 — created.
- **Evidence Classification:** Verified

**Content:** Conversion should be the result of informed confidence, not missing information or
pressure.

**Figure 4.1 — Marketplace Conversion Path:** Relevant discovery → Accurate recognition →
Clear value → Credible proof → Suitable price/availability → Low-friction choice → Reliable
fulfilment. Content cannot compensate permanently for poor product, price, stock, delivery, or
reviews.

**Listing Information Architecture:**

| Listing element | Customer job |
|---|---|
| Title | Identify exact product, type, variant, size, and relevant approved descriptor |
| Hero image | Confirm exact product and pack |
| Supporting images | Explain benefits, use, details, context, and trust |
| Bullets/key features | Enable rapid evaluation |
| Description/A+ | Provide deeper product and brand understanding |
| Variant relationship | Help customers select correctly |
| Price/offer | Clarify current commercial choice |
| Reviews/questions | Provide social proof and uncertainty reduction |
| Delivery/availability | Set transaction expectation |

## KO-SC-CH4-011 — Chapter Governance Summary

- **Purpose:** Preserve the chapter's closing governance content.
- **Scope:** Common Mistakes, Best Practices, Action Checklist, Key Takeaways, Chapter Summary.
- **Inputs:** MUV Knowledge Library, Part VIII, Ch.39, closing subsections.
- **Outputs:** Consolidated do/don't reference; 12-item Action Checklist; 4 Key Takeaways;
  Chapter Summary.
- **Dependencies:** KO-SC-CH4-001 through 010.
- **Relationships:** Mirrors the established pattern.
- **Governance Rules:** No new rule invented.
- **Validation Rules:** All 12 checklist items in original order.
- **Version:** 1.0
- **Status:** Founder Review Ready
- **Change History:** 2026-07-31 — created.
- **Evidence Classification:** Verified

**Content:**

**Common Mistakes:** Using the wrong bottle or label in the hero image. Hiding important
product differences. Writing for the algorithm rather than the customer. Overloading image
text. Leaving price or pack information inconsistent. Treating conversion increase as success
despite rising returns. Testing multiple elements without a hypothesis.

**Best Practices:** Build listings from canonical product sources. Review the full mobile
journey. Give each image one job. Use review questions to improve education. Diagnose
conversion by stage. Evaluate experiments with return and customer-quality guardrails.

**Action Checklist:**
- [ ] Exact SKU, product, variant, size, and pack verified.
- [ ] Title and category accurate.
- [ ] Hero and supporting images preserve product truth.
- [ ] Claims link to approved evidence.
- [ ] Search terms are relevant and honest.
- [ ] Bullets and description answer customer questions.
- [ ] Price, offer, stock, and delivery current.
- [ ] Reviews and Q&A monitored.
- [ ] Mobile presentation checked.
- [ ] Conversion diagnostics include returns and repeat.
- [ ] Experiments are controlled.
- [ ] Other channels remain consistent.

**Key Takeaways:** Conversion should express informed confidence. Marketplace content must
connect product, price, stock, proof, reviews, and fulfilment. Search optimisation cannot
weaken customer truth. Conversion quality includes returns, repeat, and long-term trust.
