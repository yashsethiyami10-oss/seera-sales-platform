**Content:**

The sourced process (water base → surfactant dissolution → co-solvents → acid → antimicrobial
agent → colour → fragrance, filter, transfer) follows a standard, generically-understood
sequencing logic: water-soluble surfactant (SLES) is dissolved into the aqueous base first,
followed by co-solvents (Butyl Cellosolve, then IPA), then the acid and BKC are added once the
base solution is stable, with colour and fragrance added last (as is standard practice broadly,
to avoid colour/fragrance degradation from earlier, more reactive mixing steps). This is a
generic process-chemistry inference from the stated step order, **not a rationale stated in the
SOP itself** — the SOP gives quantities, order, and mix times, but no "why" explanation for any
step, unlike Bathroom Cleaner's SOP which had one explicit safety rationale sentence.

**Relevant Knowledge Library governance context:** the Knowledge Library's "Mixing Discipline"
section explicitly names Glass Cleaner as one of several product categories where "product-specific
order must come from an approved SOP" and warns against improvising addition order for
process-sensitive materials (acids, fragrance) outside that approved SOP. This package treats the
SOP's own stated 9-step order as authoritative and does not suggest any deviation from it.

**No manufacturing safety rationale exists in this SOP** — unlike Bathroom Cleaner's "Never add
water into acid" instruction, Glass Cleaner's SOP contains zero safety-relevant process guidance
of any kind, despite handling Acetic Acid, BKC, and IPA. See `09_Safety_and_Risk.md`.
